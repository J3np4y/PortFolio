01 · Proyecto educativo · SaaS de documentación con IA

Nexora: documentación empresarial con respuestas y fuentes

Ver repositorio ↗

Problema

La documentación de equipo crece y se dispersa. Nexora ofrece un espacio privado para organizarla, encontrar información y preguntar en lenguaje natural con respuestas respaldadas por fuentes.

Arquitectura y decisiones

Next.js y TypeScript para la interfaz, con proxy same-origin para mantener la sesión en el servidor; FastAPI y Python para la API. PostgreSQL frente a SQLite permite probar restricciones y migraciones sobre el mismo motor que pgvector necesita. SQLAlchemy síncrono simplifica el primer flujo persistente y Alembic versiona el esquema. OpenAI aporta embeddings y generación; la recuperación, el filtrado por organización y las citas siguen bajo control de la API.

Solución

Autenticación por sesión revocable en cookie HttpOnly, organizaciones con roles, invitaciones, gestión y extracción de documentos PDF/DOCX/TXT, búsqueda en español y respuestas con citas. Docker Compose separa frontend, API y base de datos.

Resultados verificables

80 pruebas backend y 25 frontend, con CI documentada como aprobada. La cuota limita cada organización a 20 operaciones RAG diarias y 200 mensuales. Es un prototipo educativo: sin despliegue público, no preparado para producción y sin métricas de uso reales.
