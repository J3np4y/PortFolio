01 · Juego web · Java compilado a JavaScript

Buscaminas: lógica Java en una web estática

Abrir demo ↗

Problema

Ejecutar un juego con reglas y estado no triviales en GitHub Pages, un alojamiento estático, sin necesitar un servidor de aplicación.

Arquitectura y decisión

Separé modelo, controlador y puente web en Java. Elegí TeaVM para compilar la lógica a JavaScript y mantener la demo publicable como archivos estáticos, sin backend ni librerías JSON adicionales.

Solución

Primera jugada segura, revelado en cascada, banderas, condición de victoria y tres dificultades; la interfaz HTML/JavaScript consume el estado serializado por la API web.

Impacto comprobable

12 pruebas JUnit para reglas y casos límite; tres niveles con tableros de 9×9, 16×16 y 16×30, y 10, 40 y 99 minas, respectivamente. No se publican métricas de usuarios ni de negocio.

02 · Juego web · HTML, CSS y JavaScript

3 en Raya: juego de navegador sin dependencias

Abrir demo ↗

Problema

Modelar un juego por turnos con detección de victoria, empate y reinicio sin añadir complejidad de infraestructura.

Arquitectura y decisión

JavaScript nativo y DOM en un único archivo HTML: apropiado para un alcance pequeño, fácil de ejecutar y sin dependencias o proceso de build.

Solución

Tablero 3×3 para dos jugadores, alternancia X/O, evaluación de las ocho combinaciones ganadoras, detección de empate y reinicio.

Impacto comprobable

Demo autocontenida que se publica en páginas estáticas y se ejecuta directamente en el navegador. No hay datos públicos de uso o métricas comerciales.

Código fuente en GitHub ↗ Colección de juegos ↗
